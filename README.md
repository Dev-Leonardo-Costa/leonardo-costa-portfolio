## Sobre o projeto

Este repositório reúne meu portfólio pessoal como desenvolvedor backend, com uma apresentação moderna de minha atuação em engenharia de software, projetos em destaque e experimentos técnicos focados em desafios reais de sistemas distribuídos e APIs.

A interface foi construída com Next.js e apresenta:

- apresentação profissional e visão de engenharia
- projeto em destaque com arquitetura de backend
- seção de "Engineering Lab" com estudos e experimentos
- stack tecnológica alinhada ao meu trabalho principal
- foco em clareza, organização e comunicação técnica

## Perfil profissional

Sou um desenvolvedor backend com foco em:

- Java

## Destaques do portfólio

### Banco / Fintech API

A seção principal do portfolio apresenta um case de projeto de plataforma bancária, com foco em:

- autenticação e autorização
- regras de negócio financeiras
- persistência e versionamento de schema
- operações de PIX
- arquitetura orientada a contexto e clareza de responsabilidade
- ambiente reproduzível com Docker

### Engineering Lab

A área de laboratório reúne ideias e experimentos técnicos em backend, incluindo:

- idempotência em operações financeiras
- processamento assíncrono
- cache e estratégia de performance
- resiliência de APIs
- observabilidade e monitoramento
- testes de carga

## Como rodar localmente

Clone o repositório:

```bash
git clone https://github.com/Dev-Leonardo-Costa/leonardo-costa-portfolio.git
cd leonardo-costa-portfolio
```

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

Abra no navegador:

```text
http://localhost:3000
```

## Scripts disponíveis

```bash
npm run dev     # inicia o servidor de desenvolvimento
npm run build   # gera a build de produção
npm run start   # inicia a aplicação em produção
npm run lint    # executa a análise estática do projeto
```
